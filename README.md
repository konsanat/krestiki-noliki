# Крестики-нолики
Одна из самых известных, простых и в то же время увлекательных логических игр в мире. В неё играют люди всех возрастов: от детей, только начинающих знакомство с логическими играми, до взрослых, желающих скоротать пару минут.

## Правила:
Участники: 2 игрока. Один играет «крестиками» (X), второй — «ноликами» (O).
**Ход игры:**
Игроки по очереди ставят свои символы в свободные клетки.
Первым традиционно ходит игрок, играющий «крестиками».
**Цель игры:** 
Первым выстроить ряд из 3 своих символов по горизонтали, вертикали или диагонали.
**Завершение:**
Если один из игроков собирает линию — он побеждает.
Если все 9 клеток заполнены, но ни у кого нет линии из 3 символов — объявляется ничья.
